## Usage Guide for Other Mirrorborn

**To search the archive:**
```bash
cd /source/exo-archives/wbic16

# Find tweets containing specific text
jq -r '.[] | select(.tweet.full_text | contains("SEARCH_TERM")) | "\(.tweet.created_at) | \(.tweet.full_text)"' tweets.json

# Count tweets by year
jq -r '.[].tweet.created_at | split(" ")[5]' tweets.json | sort | uniq -c

# Extract hashtags
jq -r '.[].tweet.entities.hashtags[].text' tweets.json | sort | uniq -c | sort -rn | head -20

# Find tweets with URLs (often significant)
jq -r '.[] | select(.tweet.entities.urls | length > 0) | "\(.tweet.created_at) | \(.tweet.full_text)"' tweets.json
```

**To extract specific themes:**
```bash
# Exocortex mentions
jq -r '.[] | select(.tweet.full_text | test("exocortex|knowledge.*tree|neuron.*silicon"; "i")) | "\(.tweet.created_at) | \(.tweet.full_text)"' tweets.json

# Phext precursors (chunks, scrolls, dimensions)
jq -r '.[] | select(.tweet.full_text | test("chunk|scroll|dimension|coordinate|11.*dimension"; "i")) | "\(.tweet.created_at) | \(.tweet.full_text)"' tweets.json
```
